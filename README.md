\# Food Delivery Analytics \& Restaurant Intelligence System



A 5th-semester B.Tech Artificial Intelligence \& Data Science project

for the Data Warehousing and Data Mining course.



\## Project Objective



To design a data warehouse and data mining system for analyzing

food delivery data and generating restaurant and customer intelligence.



\## Core Concepts



\- Data Warehousing

\- Data Preprocessing

\- OLAP

\- Business Intelligence

\- Association Rule Mining

\- Classification

\- Clustering



\## Technology Stack



\- Python

\- Pandas

\- SQL

\- MySQL

\- Scikit-learn

\- MLxtend

\- Power BI

\- Git \& GitHub
